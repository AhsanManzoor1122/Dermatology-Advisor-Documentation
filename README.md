# AI-Based Dermatology Advisor

## Overview
An end-to-end computer vision and data engineering solution developed to assist in the early detection and classification of multi-class skin diseases.

## Key Features
- **Data Engineering:** Curated, cleaned, and preprocessed a multi-class skin disease dataset.
- **Predictive Modeling:** Trained and optimized a custom computer vision model for accurate disease classification.
- **Backend Deployment:** Integrated the data pipeline into a modular Python backend for real-time inference.
